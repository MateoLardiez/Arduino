# Cosas importantes a saber

## Datos de materiales
- Las luces leds tienen el positivo en el metal mas largo y el negativo en el mas corto y van con un resistor siempre para reducir la potencia
- El cable a tierra va con negativo en la BreadBoard siempre. 
- El resistor va del negativo al positivo
- En el BreadBoard, el positivo y negativo conducen en linea vertical. Los demas coducen horizontalmente
